# Canva Application

A working in-browser design studio — a forward-looking concept of what a real Canva-like application feels like to use.

## What it is

An interactive concept prototype: a project dashboard plus a full editor with draggable layers, editable text, shapes, image uploads, drawing tools, color/type/opacity controls, zoom, undo/redo, and SVG export.

## Run it

Open `index.html` in any modern browser, or visit the live site via GitHub Pages.

## Notes

- Concept prototype for portfolio and design exploration — not affiliated with Canva.
- Work is not saved between visits; export your designs as SVG to keep them.
